# 📊 Data Analyst Job Market Analysis Using SQL

## Project Aim

This project analyzes Data Analyst job postings to identify:

- Top-paying Data Analyst jobs
- Skills required for top-paying roles
- Most in-demand Data Analyst skills
- Highest-paying skills
- Optimal skills to learn based on demand and salary

## Questions Answered

1. What are the top-paying jobs for Data Analysts?
2. What skills are required for these top-paying roles?
3. What are the most in-demand skills for Data Analysts?
4. What are the top skills based on salary?
5. What are the most optimal skills to learn?
   - High Demand
   - High Paying

## Dataset

The analysis uses three main tables:

- `job_postings_fact`
- `skills_job_dim`
- `skills_dim`

## SQL Concepts Used

- Joins
- CTEs
- Aggregations
- Subqueries
- Filtering
- Grouping
- Sorting

## Key Outcome

The project provides data-driven insights into which skills offer the best career opportunities for aspiring Data Analysts by evaluating both market demand and salary potential.
